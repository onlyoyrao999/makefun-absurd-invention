# The Self-Blaming Toaster

One-sentence absurd invention pitch for make.fun's
**One-Sentence Absurd Invention Pitch** bounty
([bounty page](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)).

## The pitch

> The Self-Blaming Toaster burns your toast on purpose, then prints a
> tearful apology letter signed by the bread itself, so you can finally
> blame breakfast instead of admitting you forgot it again.

## How it works

`main.py` writes the pitch — one sentence, 195 characters — to
`/output/entry.txt`, where the competition's gate checks it (1–220
characters, UTF-8, not only whitespace) and the house judge ranks it on
how funny, clever and original the invention is.

## Run it

```sh
python3 main.py
```
